# .github

Default community health files for my repositories.

`FUNDING.yml` points the ❤️ Sponsor button at [ko-fi.com/rickapps](https://ko-fi.com/rickapps).
It applies to every public repository that does not carry its own `.github/FUNDING.yml`,
including ones created from now on. A per-repository file overrides it:
[TABifier](https://github.com/RickUsingGitHub/TABifier) has its own Ko-fi page and uses that.

Note that each repository also needs **Settings → General → Features → Sponsorships**
ticked before the button appears.
